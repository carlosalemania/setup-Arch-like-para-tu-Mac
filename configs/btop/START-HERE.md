# 🎨 EMPIEZA AQUÍ - TEMAS BTOP ÉPICOS

## ⚡ Instalación en 3 Pasos

### 1️⃣ Ejecuta el instalador
```bash
~/btop-themes-custom/INSTALL-NOW.sh
```

Te pedirá tu password de macOS para arreglar permisos.

### 2️⃣ Activa el alias
```bash
source ~/.zshrc
```

### 3️⃣ ¡Usa los temas!
```bash
btop-theme
```

## 🎮 Uso Rápido

### Cambiar tema interactivamente
```bash
btop-theme
```

### Abrir btop
```bash
btop
```

### Cambiar tema dentro de btop
Presiona `t` → Flechas → Enter

## ⌨️ Atajos Útiles en btop

|-------|--------|

| `+` `-` | Velocidad de actualización |
| `f` | Filtrar procesos |
| `k` | Kill proceso |
| `ESC` | Menú |
| `q` | Salir |

## ❓ Ayuda

### Temas no aparecen
```bash
ls ~/.config/btop/themes/
# Deberían aparecer 4 archivos .theme
```

### Alias no funciona
```bash
source ~/.zshrc
# Luego intenta de nuevo
```

### Permission denied
```bash
sudo chown -R $USER:staff ~/.config/btop
```
